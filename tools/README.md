# 上下半弧计算

以相邻两个翻刃起点为完整区间，以滚落线时刻作为切割点；视频人工校核值优先于自动估计：

- 上半弧：本次翻刃起点 `start` → 滚落线 `split`。
- 下半弧：滚落线 `split` → 下一次翻刃起点 `end`。
- 时长分别为 `split − start`、`end − split`。
- 行程分别为两个区间内 `v(t) / 3.6` 的时间积分；速度使用页面内嵌的主链路速度，单位 km/h，积分结果为米。

使用梯形积分，并在边界插值。相同时间戳保留最后一个采样，避免重复计时。上下半弧的行程之和须等于完整区间的积分；时长之和须等于 `end − start`。

半弧转向占比在同一区间对主链路 Yaw 的同向正转速积分。两脚载荷分配也在相同半弧区间按时间积分。主链路切弯点不替代翻刃起点。

缺少起止翻刃记录、滚落线在区间外或区间数据缺失时，不计算半弧比值。自动估计若未越过滚落线参照，也不计算半弧比值；已经人工校核的点不受 Yaw 是否过零限制。

人工校核记录见 [fallline_annotations.json](fallline_annotations.json)。视频时间按 `HH:MM:SS:百分之一秒` 解析，再加页面的 `wmd` 对齐偏移转换成传感器时间。保存原自动估计值 `tfl_auto` 和标注来源，后续生成时优先应用校核值。当前记录为周占双 T5–T8：12:10:44.55、12:10:47.26、12:10:49.22、12:10:50.92（最后一条已确认为 T8）。

其余弯的自动估计仍使用去除整趟线性漂移后 Yaw 过零的时刻；整趟平均朝向不保证等于真实山下方向。

实现：[arc_cycle.py](arc_cycle.py)。复核页面全部内嵌数据：

```sh
python tools/test_arc_cycle.py
```

需要 NumPy。测试包括边界位于采样间隙、两次翻刃与主链路切弯点不重合、翻刃缺失、滚落线在区间外、重复时间戳和缺失速度记录。
