# 双脚 Roll 均值过零切弯与上下半弧

## 当前切割口径

使用页面左右脚 Roll 曲线的均值 `r(t) = (rollL(t) + rollR(t)) / 2`，沿同一条 0 轴，在相邻两次交替过零之间划出完整区间。正值区间对应后刃，负值区间对应前刃。Roll 图新增深灰均值曲线、0 轴上的过零点及边界线。

- 上半弧／上半弯：起始均值过零 `start` → 滚落线 `split`。
- 下半弧／下半弯：滚落线 `split` → 下一次均值过零 `end`。
- 两种称谓共用同一组起止点与切分点。点事件采用 `[start, split)` 与 `[split, end)`，结束点归入下一个区间。
- 时长：`split − start`、`end − split`。
- 行程：在两个区间分别对主链路速度 `v(t) / 3.6` 做梯形积分，边界插值，单位米。

均值直接来自页面的 `rollL`、`rollR`，不额外平移零轴。只把变号算作过零；碰到 0 后返回同一侧不产生新边界。连续停在 0 轴后变号，取零值平台的中点作为一次过零；普通采样间过零用线性插值。缺少任一脚时不跨越缺失段插值，重复时间戳保留最后一条。

保留原弯号、视频片段、App 分数及原弯指标。对每张原弯卡片，在同刃方向的 Roll 正负区间中，选择与其原始时间范围重叠最长的一段；相同 Roll 区间若对应多个原弯，明确显示无法唯一划分。均值的每个真实变号都保留，边界不会跳过中间一次反向过零。

转向占比、半弧行程、载荷峰归属、两脚半弧载荷分配、半弧速度回落及上下半弯摔倒归属都使用上述区间。弯尾近直时间止于结束 Roll 均值过零点。其他原弯指标仍标作原弯指标，App 分数沿用主链路输出。

实现：[roll_boundaries.py](roll_boundaries.py)、[arc_cycle.py](arc_cycle.py)。没有完整唯一的 Roll 区间、滚落线不可靠或不在区间内时，不强行计算半弧比例。

## 滚落线算法

实现：[fallline_detector.py](fallline_detector.py)，版本 `yaw-route-fusion-v1`。运行时只有一个全局校准参数 `λ = 0.65`，不读取视频标注，不按滑手、趟次或弯号覆盖时间。

对整个记录展开主 Yaw 并去除线性漂移，记为 `ψ(t)`。沿用已有路线角速度 `ω_route`（两脚平均侧向加速度 ÷ 速度，以板子转向确定符号），在本弯起始峰值 `a` 锚定路线方向：

```text
ρ(t) = ψ(a) + ∫[a,t] ω_route(u) du
h(t) = (1 − λ) ψ(t) + λ ρ(t)
```

在 `t0 → t1` 内，取沿本弯转向的 `h(t)` 过零点；多个候选时取离区间中点最近者，采样间线性插值。这样利用路线与板向的差异修正原先仅用 Yaw 平均朝向的过早切点。

融合信号未过零时回退到 Yaw 过零点并标记 `yaw_fallback`；两种信号都未穿越时标记 `unresolved`，只显示最近参照点，半弧与直接依赖滚落线的相位结论留空。

传感器输入按页面发布精度统一到秒、弧度和弧度/秒各三位小数。离线分类回放与页面生成共用此算法，避免不同输入精度导致边界不一致。

## 四个点用于校准

来源为本会话用户提供的视频时刻；最后一条已确认为 **T8**。时间码末两位为百分之一秒。仅离线校准与测试使用 [标注文件](fixtures/fallline-calibration.json)，不进入运行时查表逻辑。

| 周占双 | 用户标注 | 新算法估计 | 误差（估计 − 标注） |
|---|---|---|---:|
| T5 | 12:10:44.550 | 12:10:44.594 | +0.044 s |
| T6 | 12:10:47.260 | 12:10:47.313 | +0.053 s |
| T7 | 12:10:49.220 | 12:10:49.168 | −0.052 s |
| T8 | 12:10:50.920 | 12:10:50.875 | −0.045 s |

最大绝对误差 **0.053 s**，平均绝对误差 **0.0485 s**。每次用三个点拟合权重、预测剩余一点，四次留出检查的最大误差为 **0.073 s**。完整计算见 [calibration-report.json](calibration-report.json)，可用 [calibrate_fallline.py](calibrate_fallline.py) 重算。

比较过固定时间偏移、固定角度偏移、固定弯内比例和路线融合四种单参数模型，逐点留出最大误差分别为 0.115、0.134、0.207、0.073 秒：[候选比较](candidate-comparison.json)。

这四点来自同一位滑手。它们能检查当前校准的拟合与稳定性，不能证明其他滑手、其他雪坡或全部 587 个弯的真实滚落线准确率。
